# D3 Coffee Sales Bar Chart

## Overview
This project displays a beginner visualization built using D3. The goal is to demonstrate skills in loading data, creating scales and axes, and building a basic bar chart using SVG elements.

## Dataset
Dataset was simplified to include only 2 columns and aggregated to reflect total sales:
  - coffee_name: type of coffee sold, with over 8 types
  - money: total sales generated by each coffee category
Data was retrieved from the source: https://www.kaggle.com/datasets/anassarfraz13/coffee-sales-dataset?resource=download&select=Coffe_sales.csv

## Visualization
The bar chart displays coffee types on the x-axis and their corresponding sales values on the y-axis. Each bar represents a coffee category, and the height represents the value of sales.

The visualization includes:
- CSV data loading
- Data formatting and type conversion
- ScaleBand (x-axis) and ScaleLinear (y-axis)
- SVG-based rendering
- Axes generation
- Bar creation using data binding
